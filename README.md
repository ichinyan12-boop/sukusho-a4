# スクショ・写真をA4に並べて印刷

スマホのスクリーンショットや写真を、順番どおり・切らずに、A4に2〜9枚ずつ並べて印刷またはPDFにする無料のWebツールです。

使う: https://ichinyan12-boop.github.io/sukusho-a4/

- 並べる順: 選んだ順 / ファイル名の順（数字も正しく）/ 撮影日時の順。タップや矢印で並べ替え可
- 1枚の紙に 1・2・3・4・6・8・9枚、A4縦・横
- 画像は縦横比を保ったまま入り、切れません
- 通し番号・日時・ファイル名・見出し・ページ番号を添えられます
- 画像はサーバーへ送信されず、端末の中だけで処理します（PDF作成に jsPDF を cdnjs から読み込みます）

不具合や要望は Issues へどうぞ。
